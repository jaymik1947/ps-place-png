能力

它替你做的六件事

🔗

按名配对

去掉扩展名转小写做 key，png / tif / jpg 都认，png 优先。

🎭

Alpha 通道应用

PSD 里若有名为 Alpha 的通道，自动载入为选区生成蒙版；没有就跳过。

📐

原点对齐

置入后按 bounds 把左上角归零，与画布严丝合缝，不做缩放。

📦

收进 aov 组

两个图层自动归组并隐藏，画面上只留背景层。

🛡️

失败不落盘

任一图层置入失败，该 PSD 整体不保存，原文件保持完好。

🔁

可重复运行

每次先清掉已有的 mat / obj 图层，跑多少次结果都一样。

安装

菜单脚本版

五分钟搞定，之后一直在脚本菜单里。

下载 jsx

从仓库拿 menu-script/place-png-into-psd.jsx。

转成 GBK 编码

这一步不能省。ExtendScript 在中文 Windows 按 CP936 解析脚本，存 UTF-8 会让所有中文提示变乱码。

# Windows PowerShell，在同目录执行
[IO.File]::WriteAllText('批量置入PNG到PSD.jsx', `
  [IO.File]::ReadAllText('place-png-into-psd.jsx','utf8'), `
  [Text.Encoding]::GetEncoding(936))

放进 PS 脚本目录

需要管理员权限。

C:\Program Files\Adobe\Adobe Photoshop 20xx\Presets\Scripts\

重启 Photoshop

菜单里出现 文件 → 脚本 → 批量置入PNG到PSD 就成功了。

⚠️
覆盖保存不可逆。第一次先拿 3～5 组文件试跑，确认图层顺序和 Alpha 方向都对，再处理全量。
配置

改两行就能适配你的目录

两份 jsx 顶部都有配置区，目录名、图层名、组名都能改。

配置项默认作用
MAT_DIRmat_2材质层所在子文件夹
OBJ_DIRobj_1物体层所在子文件夹
PSD_DIRrgba目标 PSD 所在子文件夹
AOV_GROUPaov两者被收进的组名，该组隐藏
ALPHA_NAMEalpha要应用的通道名，找不到跳过
ALPHA_INVERTfalseAlpha 极性相反时改 true
SAVEtrue是否覆盖保存原 PSD
TEST_FIRST_ONLYfalse只处理第一个，调试用

# 直接把仓库丢给 AI，附上这段背景

两个版本共用一套逻辑：
  menu-script/place-png-into-psd.jsx   ExtendScript 菜单脚本
  cep-panel/host/js/main.js            CEP 前端（Chromium）
  cep-panel/host/jsx/host.jsx          CEP 后端（ExtendScript）

硬约束：
  · ExtendScript 是 ES3，不能用 let/const/箭头函数/JSON 对象
  · 两份 jsx 是同一逻辑的两份拷贝，改逻辑必须同步
  · 菜单版交付前必须转 GBK，CEP 版保持 UTF-8
  · evalScript 不能传非 ASCII，中文必须 URL 编码
  · 跨文档复制图层用 duplicate(destDoc)，别传第二个参数

仓库 README 里有更详细的坑位说明和「想改 X 该动哪个函数」对照表。
